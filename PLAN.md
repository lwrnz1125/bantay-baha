# Sprint Planning

## User Stories
1. **As a resident**, I want to see the current water level and a simple advisory so that I know if I need to evacuate.
   * *Acceptance Criteria:* Ang water level ay naka-display gamit ang tamang kulay (Normal, Alert, Danger). May nakasulat na advisory sa English at Filipino.
2. **As a barangay official**, I want to see the trend of the water level over the last hour so that I can prepare emergency responses.
   * *Acceptance Criteria:* May line chart na nagpapakita ng latest readings. May analytics summary kasama ang trend.
3. **As a user**, I want the app to update automatically so that I don't have to keep refreshing the page to see changes.
   * *Acceptance Criteria:* Ang front end ay awtomatikong kumukuha ng bagong data mula sa API tuwing 5 segundo nang hindi nagre-reload ang page.
